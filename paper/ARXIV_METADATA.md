## Abstract

We develop an exact-certification pipeline for the degree-17
Bachoc-Vallentin three-point semidefinite-program bound on the
11-dimensional kissing number. The reported numerical objective is
868.82650. The target proof fixes the objective at the rational value
86899/100. A compact exact feasible solution at this value passes primary
Julia verification and independent release-mode replay, establishing
`tau_11 <= 868`. The pipeline separates high-precision numerical solving,
exact affine projection, rational positive-semidefiniteness verification,
and independent certificate replay. All 70 matrix blocks and every exact
coefficient identity pass. The final prior-art refresh completed on
2026-09-10 without locating an equivalent public certificate.
